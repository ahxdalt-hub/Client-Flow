# Marketloom

Blank slate. The previous storefront (Shopify store research pack) has been
removed. Only the MarketLoom name and logo remain.

## Stack

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```
